La topologia se esta haciendo para 2 redes, En este proyecto se diseña y configura en Cisco Packet Tracer una red basada en la dirección 10.0.0.0/16, con:

  • Segmentación por VLAN en los switches.
  • Cada router trabajando con su propia subred.
  • Configuración de direcciones IPv4, máscaras, default gateway y puertos de enlace.
  • Configuración de rutas estáticas entre routers.
  • Guardado de la configuración con el comando write memory.
  1. Decidir qué red se va a usar:
    • Red base: 10.0.0.0/16.
  2. Definir las subredes y los hosts que tendrá cada una.
  3. Aplicar segmentación por VLAN en los switches.
  4. Asignar a cada router su propia subred.

El resultado de este paso es un esquema claro de subredes, VLAN y routers.
  1. En Cisco Packet Tracer, crear la estructura de la red:
    • Colocar los dispositivos necesarios (routers, switches, hosts).
    • Conectarlos con los enlaces correspondientes.
  2. Verificar que la topología refleja la planificación de subredes y routers definida en el paso anterior.
  1. Definir los detalles de cada subred:
    • Número de dispositivos que pertenecerán a esa subred.
    • Dirección de red y máscara asociadas.

  1. En los dispositivos finales (hosts), configurar:
    • La IPv4 Address correspondiente a la subred.
    • La Subnet Mask de la subred.
    • El Default Gateway (IP del router para esa subred).

  1. Asegurarse de que en la configuración principal de cada dispositivo están correctamente establecidos:
    • ipv4 address
    • subnet mask
    • Puerto de enlace (interfaz por la que sale el tráfico).
  1. En los switches, establecer las VLAN necesarias.
  2. Utilizar la opción ADD para crear cada VLAN.
  3. Asignar a cada VLAN un nombre representativo.
  1. Añadir las VLAN en las interfaces conectadas al switch. Colocamos la primera interfaz que hace referencia al switch en TRUNK para que pueda llevar el trafico de todas las vlan
  2. Asignar cada puerto del switch a la VLAN que le corresponda según la subred y el dispositivo conectado.
  3. Verificar que todos los puertos usados por los dispositivos están correctamente asociados a su VLAN.
  1. Configurar en el router la primera interfaz que hace referencia a la subred correspondiente.
  2. Establecer en esa interfaz la dirección IPv4 y la máscara según el esquema de subredes definido (por ejemplo, la configuración indicada en el documento para direcciones como 10.0.1.65 255.255.255.192).
  3. Repetir el proceso para las demás interfaces del router que deban dar servicio a otras subredes.
  4. Al finalizar este paso, el router queda configurado para las subredes que gestiona.

  1. Configurar la IPv4 y la máscara en las interfaces de los routers utilizadas para enlazarlos entre sí.
  2. Verificar que:
    • Cada enlace entre routers tiene una subred claramente definida.
    • Las direcciones en cada extremo del enlace son coherentes entre sí.
  3. Comprobar conectividad básica (ping) entre routers a través de esas interfaces.
  1. Configurar el enrutamiento estático (rutas estáticas) en los routers de las subredes:
    • Añadir rutas que permitan llegar al resto de subredes a través del router principal.
  2. Repetir la configuración de rutas estáticas en los routers de las subredes (en el documento se mencionan específicamente Router0 y Router1).
  3. En el router que conecta directamente con Internet (Router2):
    • Añadir todas las direcciones de red de las subredes como rutas estáticas.
    • Asegurarse de que Router2 conoce todas las redes internas.
  1. En cada switch y router, guardar la configuración con el comando:
    write memory
  2. Confirmar que, tras guardar, la configuración permanece aunque se reinicie el dispositivo.

Al completar estos pasos:

  • La red 10.0.0.0/16 queda dividida en subredes, cada una asociada a VLAN concretas en los switches.
  • Cada router gestiona su subred correspondiente con las interfaces IPv4 configuradas.
  • El routing estático permite la comunicación entre todas las subredes.
  • El router conectado a Internet conoce todas las redes internas.
  • Toda la configuración está guardada de forma permanente en los switches y routers.
